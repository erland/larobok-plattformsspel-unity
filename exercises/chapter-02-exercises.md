# Övningar till kapitel 2: Förstå Unitys arbetsyta

## Övning 1: Fönsterkarta

Öppna Unity-projektet `Skogsspranget` och hitta följande fönster:

- Scene view
- Game view
- Hierarchy
- Inspector
- Project
- Console

Skriv en kort förklaring till varje fönster med dina egna ord.

## Övning 2: Två objekt i scenen

Skapa två GameObjects i `MainScene`:

```text
Ground
Player
```

Placera `Player` ovanför `Ground`. Ändra storlek på `Ground` så att det fungerar som en enkel testplattform.

Kontrollera:

- att båda objekten finns i Hierarchy
- att du kan markera dem ett i taget
- att Inspector ändras beroende på vilket objekt som är markerat

## Övning 3: Transform-experiment

Markera `Player` och ändra värden i Transform.

Testa att ändra:

- Position X
- Position Y
- Scale X
- Scale Y

Skriv kort vad varje ändring gör i Scene view.
